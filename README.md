# Microsoft Intune Administration Lab

## Project Overview

This repository documents my **Microsoft Intune Administration** lab, where I practised common endpoint management tasks performed by an **IT Support Technician** using Microsoft Intune and Microsoft Entra ID.

Throughout this project, I enrolled and managed **Windows devices**, configured **device and compliance policies**, implemented **endpoint security controls**, managed application deployment, and worked through common **device management and troubleshooting** scenarios. I also used **Microsoft Entra ID groups** to organise users and devices and assign Intune policies within a cloud-managed environment.

## Project Sections

### 📁 01 - Entra ID and Device Enrolment

Configure Microsoft Entra ID groups and enrol Windows devices into Microsoft Intune for centralised endpoint management.

### 📁 02 - Device Configuration and Compliance

Create and assign device configuration profiles and compliance policies to centrally manage Windows device settings and evaluate device compliance.

### 📁 03 - Endpoint Security

Configure Microsoft Defender Antivirus, BitLocker encryption, and endpoint security controls to protect managed Windows devices.

### 📁 04 - Application Management

Configure and deploy applications to managed devices using Microsoft Intune, while controlling application assignments through appropriate user or device groups.

### 📁 05 - Device Lifecycle and Troubleshooting

Manage endpoint lifecycle tasks including device synchronisation and decommissioning, while investigating and resolving common Intune policy, compliance, and device management issues.
